# 품 드라이브 (Poom Drive)

> 동승자와 운전자를 함께 챙기는 Pleos Connect 차량용 앱

## 프로젝트 소개
품 드라이브는 차량에 누가 탑승했는지 인식하고, 탑승자에 맞춰 부드러운 운전·실내 공기·휴식을 음성으로 안내하는 차량용 앱입니다. 운전자가 혼자 탑승한 경우에는 운전자의 자세와 휴식을 관리합니다.

본 프로젝트는 현대자동차그룹 차량용 앱 개발 공모전(Code your App into Pleos App Market) 출품작이며, 현재 개발을 진행하고 있습니다.

## 주요 기능
| 탑승 모드 | 기능 |
|---|---|
| 아이 동승 | 출발 전 카시트 점검 음성 안내, 동화 읽어 주기, 뒷좌석 더위 알림 |
| 부모님 동승 | 급제동·급회전 음성 안내, 주행 흔들림 점수, 도착 후 멀미 확인 |
| 반려견 동승 | 실내 온도·환기 안내, 2시간 간격 휴식 안내 |
| 운전자 단독 | 환기 시점 안내, 1시간 간격 자세 전환 안내, 장거리 주행 휴식·스트레칭 안내 |

- 공통: 음성 응답("응")으로 가까운 휴게소를 경유지에 추가
- 공통: 정차 중에는 화면, 주행 중에는 음성으로만 안내

## 활용 기술
| 구분 | 내용 |
|---|---|
| Pleos Vehicle SDK | 좌석 탑승, 문 열림, 공조(내기순환·풍량), 브레이크, 조향각 |
| AAOS Car API | 차속, 기어, 외기 온도 |
| Pleos NaviHelper | 경유지 추가, 목적지·경로 정보 조회 |
| Pleos TTS·STT | 온디바이스(ON_DEVICE) 음성 안내 및 음성 응답 인식 |

## 개발 환경
- 언어: Kotlin
- 플랫폼: Pleos Connect (Android Automotive OS, Android 14)
- 테스트: Pleos Connect Emulator v2.1.0, Virtual Console
